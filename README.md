# 英语练习台（影子跟读 + 生词复习）

面向英语提升的练习网站，2026-09-22 起分两个板块：

- **影子跟读**：每篇材料含英文正文（标粗生词）、生词自查表、好词好句·短语积累与全文中文翻译，配「整篇 + 分段」跟读音频。
- **生词复习**：把六级复盘生词卡与跟读材料词表合成一个复习库，翻面自评 + 选择题两种模式，按 1 / 3 / 7 / 16 / 35 天递增复扫。

桌面、手机、平板均可使用，无需安装或登录。

## 在线使用

**网站地址：<https://tobeatian.github.io/english-practice/>**

用电脑、手机或平板浏览器直接打开即可，无需安装或登录。

## 怎么用网站

**首页**：两个板块各一张卡片，卡片上直接显示「已练 X / 共 Y 篇」与「今日待复习 N · 未学 M」。

### 影子跟读

- **材料列表**：每 10 篇一组，点组标题即可展开或收起，组标题显示日期范围与篇数；顶部搜索框支持按中英文标题或编号过滤。
- **打开材料**：点卡片上的「进入阅读」打开单篇，或直接点「播放全文」先听一遍。
- **播放音频**：阅读页可播放整篇，每个自然段也有独立播放按钮；支持 0.75 / 1.0 / 1.25 倍速，每段还能开「🔁 循环」反复回听。
- **生词自查表**：四列——单词 / 词性 / 中文 / 英文释义；手机上会自动变成每个词一张卡片，方便阅读。
- **短语与翻译**：正文下方是「好词好句·短语积累」，全文中文翻译默认折叠在页面最下方，先跟读、再展开核对。
- **学习进度**：每张卡片可「标记已练」，顶部显示「已练 X / 共 Y」，还能切到「只看未练」。（进度保存在本机浏览器，换设备或清理缓存不会同步）
- **精听模式**：阅读页顶部可切换到「精听模式」，逐句播放（底部进度条可点击拖动）、写下你听到的句子，再对照答案查看逐词差异、标记错因，并查看本篇正确率与「只重练错句」。
- **连续练习**：每篇阅读页底部有「上一篇 / 下一篇」导航，方便按顺序练下去。

### 生词复习

- **只看英文**：卡片正面只有英文词/短语，先自己说词性和英文意思。点「显示答案」出**词性和英英释义**；**中文默认不显示**，点「看中文」才展开。想练发音就点「🔊 读一遍」（用浏览器自带语音，不联网）。
- **三档自评**：认识 / 模糊 / 不认识，也可以用键盘——**空格翻面、再按一次空格看中文（再按收起）**、`1` / `2` / `3` 评分。
  - 认识 → 升一盒，下次间隔 1 → 3 → 7 → 16 → 35 天；
  - 模糊 → 留在当前盒，明天再出；
  - 不认识 → 回到第 1 盒，明天再出，并且**这一轮稍后再考你一次**。
- **选择题模式**：题干是英文词，四个选项全是英文释义，干扰项优先取同一批次的同词性易混词，全程不出现中文；答对记「认识」、答错记「不认识」。
- **刷什么**：今天的一轮（到期复习 + 新词）/ 只刷到期 / 只刷新词 / 只刷错词 / **今日复习**；还能按「来源」（复盘生词 / 影子跟读）和日期筛。每轮默认上限：新词 20 张、复习 40 张，可改。
- **今日复习（2026-09-22 新增）**：把**今天刷过的卡按今天的顺序再刷一遍**——不管它是当天新词还是到期复习卡，只要今天动过就在里面；适合"刚刷完想再滚一遍"或第二天开始前热身。它只重放这一批，不改排程（认识照样升盒）。
- **出场顺序**：复盘错词 → 必背术语与句式 → 复习词库 → 跟读词表，同一类按日期新的在前（你自己的错词最先出）。
- **断点续学（2026-09-22 新增）**：一轮没刷完就关网页、或者点「结束」离开，这一轮都会存下来；下次打开时概览顶部出现「上次没刷完 · 第 6 / 20 张」的横幅，点「继续」就从那一张接着刷——队列顺序、错词重考轮、三项战绩，连"当前这张是否已翻面 / 选择题是否已作答"都会还原，**不会重复计分**。跨天有效，不设过期；真正刷完或点「放弃这轮」才会清掉。已有未完成轮次时点「开始」会先问一句再开新的。
- **学习记录**：概览底部显示今天动过多少张、连续多少天有记录、近 7 天逐日柱状（口径＝当天动过的**不同卡片数**）。
- **进度管理**：进度存在本机浏览器；换设备或清缓存前，用「导出进度」存一个 JSON（文件名 `english-practice-vocab-日期.json`，里面**连未完成的那一轮一起带走**），在新设备「导入进度」合并（同一张卡取课时更高、时间更晚的一次；本机已经有未完成轮次时保留本机那条）。

## 建议练法

1. 先扫一遍生词表和英文释义，确保看懂了大意；
2. 放音频跟读两遍：第一遍落后原声 2～3 个词，第二遍尽量与原声同步；
3. 关掉音频自己读一遍并录音，回听时只挑一个最想改的点（发音、卡壳或语调），下次专门改它。

想练听力精度时，用「精听模式」做 15 分钟逐句听写（听一句、写一句、对照差异、标记错因），再回到跟读模式练流畅度。

## 目录结构

```
英语练习台/
├── README.md               ← 本说明
├── 2026-09-08/             ← 材料按生成日期归档（md/mp3，本地留存）
├── publish.ps1 / 发布网站.bat  ← 一键构建并发布
├── scripts/
│   ├── build_site.py       ← md → 网页数据 + 分段音频（默认）
│   ├── build_vocab_deck.js ← 复盘生词卡 + 跟读词表 → web\vocab.json（复习库）
│   └── build_print_docx.py ← md → Word 打印版（按需，默认停用）
├── web/                    ← GitHub Pages 发布目录
│   ├── index.html          ← 首页（两个板块入口）
│   ├── materials.html      ← 影子跟读材料列表
│   ├── read.html           ← 单篇阅读页
│   ├── vocab.html          ← 生词复习页
│   ├── app.css / app.js / home.js / vocab.js
│   ├── materials.json      ← 跟读材料数据（由 build_site.py 生成）
│   ├── vocab.json          ← 复习库数据（由 build_vocab_deck.js 生成）
│   └── audio/              ← 整篇与分段音频副本
└── .github/workflows/pages.yml ← 自动部署工作流
```

## 技术说明

- 纯静态站点：HTML + CSS + JavaScript，无框架、无后端；
- 数据单一来源为各篇 md，网页数据与音频由脚本生成，不手工维护第二份内容；
- 复习库的单一来源是 `模拟卷\**\今日生词.md` 与 `web\materials.json`，`web\vocab.json` 由脚本生成，不手改；
- `发布网站.bat` 会依次跑 `build_site.py` → `build_vocab_deck.js` → 提交推送；任一构建失败就中止，不会发布半成品；
- 托管：GitHub Pages（GitHub Actions 发布 `web/` 目录），公开仓库 [TOBEATIAN/english-practice](https://github.com/TOBEATIAN/english-practice)（2026-09-22 由 `shadow-reading` 改名而来）。
