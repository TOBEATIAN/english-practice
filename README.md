# 英语练习台（影子跟读 + 个人生词本）

面向英语提升的练习网站，2026-09-22 起分两个板块：

- **影子跟读**：每篇材料含英文正文（标粗生词）、生词自查表、好词好句·短语积累与全文中文翻译，配「整篇 + 分段」跟读音频。
- **六级生词本**：默认空白，由你主动添加单词、短语、句式，或加入六级内置词书；内置 ECDICT 离线词典自动补音标、词性、中文释义、英文释义和词形变化，文章里出现过的词还会自动带原句语境。

桌面、手机、平板均可使用，无需安装或登录。

## 在线使用

**网站地址：<https://tobeatian.github.io/english-practice/>**

用电脑、手机或平板浏览器直接打开即可，无需安装或登录。

## 怎么用网站

**首页**：两个板块各一张卡片，卡片上直接显示「已练 X / 共 Y 篇」与「今日待复习 N · 未学 M」。

### 影子跟读

- **材料列表**：每 10 篇一组，点组标题即可展开或收起，组标题显示日期范围与篇数；顶部搜索框支持按中英文标题或编号过滤。
- **打开材料**：点卡片上的「进入阅读」打开单篇，或直接点「播放全文」先听一遍。
- **播放音频**：阅读页可播放整篇，每个自然段也有独立播放按钮；支持 0.75 / 1.0 / 1.25 倍速，每段还能开「🔁 循环」反复回听。
- **生词自查表**：五列——单词 / 词性 / 中文 / 英文释义 / **音标**；手机上会自动变成每个词一张卡片，方便阅读。
- **短语与翻译**：正文下方是「好词好句·短语积累」，全文中文翻译默认折叠在页面最下方，先跟读、再展开核对。
- **学习进度**：每张卡片可「标记已练」，顶部显示「已练 X / 共 Y」，还能切到「只看未练」。（进度保存在本机浏览器，换设备或清理缓存不会同步）
- **精听模式**：阅读页顶部可切换到「精听模式」，逐句播放（底部进度条可点击拖动）、写下你听到的句子，再对照答案查看逐词差异、标记错因，并查看本篇正确率与「只重练错句」。
- **连续练习**：每篇阅读页底部有「上一篇 / 下一篇」导航，方便按顺序练下去。

### 生词本

- **默认空白**：第一次打开没有预制词卡。可以新建多本生词本，自由切换；内置的近五年高频、真题精简和六级完整词书都需要你主动加入。
- **六级高频合订（默认推荐）**：1,074 词 = 近五年真题高频 361 词 + 真题精简中未重复的 713 词。排序保持“先高频、后扩展”，避免把两本词书简单混成字母表。
- **近五年高频组成**：361 词 = 对 2021.12–2026.06 共 15 个真题批次（含 2026 年 6 月三套）做 OCR/文本统计，保留至少在两个批次出现、并达到单场噪声阈值的六级增量词。
- **六级真题精简（扩展版）**：843 词 = 824 个本地《六级真题已考大纲词汇》+ 19 个在 2026 年 6 月三套中重复出现、且不在上表的六级增量词。已排除四级和高考基础词，适合背完近五年高频后扩大覆盖。
- **六级完整**：5,407 个 ECDICT 六级相关词条，用于查漏补缺，不建议从第一页顺序硬背。
- **添加单词或短语**：只输入词本身，词典自动补全。`postpone`、`deal with`、`be likely to` 这类单词与短语都可以放进来；词典和文章词库都没有收录时会明确标成“待补”，不会伪造释义。
- **内置词典**：来自 ECDICT（MIT 许可），当前打包四、六级相关词条、常用 2–5 词短语和真题精简书补录词共 18,077 条，按需加载，不依赖联网词典接口。
- **三步主动训练（默认）**：看词忆义 → 给中文线索写英文 → 放回原文语境或写自己的句子。三步都不提供中文四选一，最后按整张卡的真实表现决定 1 / 3 / 7 / 16 / 35 天复习间隔。
- **分项统计**：分别统计“能说词义”“能看义写词”“能语境使用”和“完成三步”，不再把选择题答对等同于会用。

### 兼容的旧复习模式

- **只看英文**：卡片正面只有英文词/短语，先自己说词性和英文意思。点「显示答案」出**词性和英英释义**；**中文默认不显示**，点「看中文」才展开。想练发音就点「🔊 读一遍」（用浏览器自带语音，不联网）。
- **三档自评**：认识 / 模糊 / 不认识，也可以用键盘——**空格翻面、再按一次空格看中文（再按收起）**、`1` / `2` / `3` 评分。
- **音标（2026-09-23 新增）**：卡片正面在单词下面直接给 IPA（如 `/biːd/`），**翻面前就能看到**——音标只提示怎么读，不泄露意思；短语逐词标音（`/ən ˌɪnˌfɔːrˈmeɪʃən gæp/`）；跟读页的生词自查表也加了音标列。**每一张词卡都有音标**（句式卡是整句模板、常含中文，不给整句标音，容易误导；构建时会卡住任何漏音标的新词）。
  - 认识 → 升一盒，下次间隔 1 → 3 → 7 → 16 → 35 天；
  - 模糊 → 留在当前盒，明天再出；
  - 不认识 → 回到第 1 盒，明天再出，并且**这一轮稍后再考你一次**。
- **选择题模式**：题干是英文词，四个选项全是英文释义，干扰项优先取同一批次的同词性易混词，全程不出现中文；答对记「认识」、答错记「不认识」。
- **刷什么**：今天的一轮（到期复习 + 新词）/ 只刷到期 / 只刷新词 / 只刷错词 / **今日复习**；还能按「来源」（复盘生词 / 影子跟读）和日期筛。每轮默认上限：新词 20 张、复习 40 张，可改。
- **今日复习（2026-09-22 新增）**：把**今天刷过的卡按今天的顺序再刷一遍**——不管它是当天新词还是到期复习卡，只要今天动过就在里面；适合"刚刷完想再滚一遍"或第二天开始前热身。它只重放这一批，不改排程（认识照样升盒）。
- **出场顺序**：复盘错词 → 必背术语与句式 → 复习词库 → 跟读词表，同一类按日期新的在前（你自己的错词最先出）。
- **断点续学（2026-09-22 新增）**：一轮没刷完就关网页、或者点「结束」离开，这一轮都会存下来；下次打开时概览顶部出现「上次没刷完 · 第 6 / 20 张」的横幅，点「继续」就从那一张接着刷——队列顺序、错词重考轮、三项战绩，连"当前这张是否已翻面 / 选择题是否已作答"都会还原，**不会重复计分**。跨天有效，不设过期；真正刷完或点「放弃这轮」才会清掉。已有未完成轮次时点「开始」会先问一句再开新的。
- **学习记录**：概览底部显示今天动过多少张、连续多少天有记录、近 7 天逐日柱状（口径＝当天动过的**不同卡片数**）。
- **进度管理**：生词本与复习进度都存在本机浏览器；换设备或清缓存前，用「导出全部数据」存一个 JSON（文件名 `english-practice-data-日期.json`，里面包含所有生词本、卡片进度和未完成轮次），在新设备用「导入全部数据」合并。

## 建议练法

1. 先扫一遍生词表和英文释义，确保看懂了大意；
2. 放音频跟读两遍：第一遍落后原声 2～3 个词，第二遍尽量与原声同步；
3. 关掉音频自己读一遍并录音，回听时只挑一个最想改的点（发音、卡壳或语调），下次专门改它。

想练听力精度时，用「精听模式」做 15 分钟逐句听写（听一句、写一句、对照差异、标记错因），再回到跟读模式练流畅度。

## 技术说明

- 纯静态站点：HTML + CSS + JavaScript，无框架、无后端；
- 数据单一来源为各篇 md，网页数据与音频由脚本生成，不手工维护第二份内容；
- 复习库的单一来源是 `模拟卷\**\今日生词.md` 与 `web\materials.json`，`web\vocab.json` 由脚本生成，不手改；
- `web\dictionary.json` 与 `web\wordbooks\*.json` 由 `scripts\build_dictionary.py` 从 ECDICT 生成；网页只保存用户选中的词形，词典释义按需加载，不复制进每本生词本；
- `web\wordbooks\cet6-compact.json` 由 `scripts\build_cet6_compact.py` 生成：824 个真题已考大纲词 + 19 个 2026 年 6 月三套中重复出现的六级增量词；不是官方频次榜，页面中按“真题精简”展示；
- `web\wordbooks\cet6-five-year.json` 由 `scripts\build_cet6_five_year.py` 生成：统计范围为 2021.12–2026.06 的 15 个批次，当前入选 361 个跨批次高频六级增量词；原始 OCR 只放临时目录，不随站点发布；
- `web\wordbooks\cet6-combined.json` 由 `scripts\build_cet6_combined.py` 生成：前 361 词为近五年高频，后 713 词为真题精简扩展词，共 1,074 词；
- 近五年高频口径：7 份历史扫描卷共 206 页按 180 dpi 渲染并做本地 Windows OCR；2021.12、2022.06、2022.09 与 2026 年 6 月三套从 Word 原稿提取，合计 15 个题库批次。词形经 ECDICT 词形变化归并，只保留带 `cet6` 且不带 `cet4`、`gk` 标签的候选词；`count + 5 × 覆盖批次数` 排序，且必须至少覆盖 2 个批次；
- ECDICT 来源：<https://github.com/skywind3000/ECDICT>，MIT 许可；许可全文随站点放在 `web\dictionary-license.txt`；
- `发布网站.bat` 会依次跑 `build_site.py`（跟读数据 + 音标列）→ `build_vocab_deck.js`（第一遍：先出卡）→ `build_ipa.py`（补新词音标）→ `build_vocab_deck.js`（第二遍：把音标写进卡里）→ 提交推送；**这个顺序不能反**——音标库的输入是刚生成的 `web\vocab.json`，先跑音标就会漏掉当天新词（2026-09-25 真实踩过）；任一构建失败就中止，不会发布半成品；
- 音标库在 `Project_02_六级\docs\生词_音标库.json`：自动部分来自**离线**发音词典 `eng_to_ipa`（CMU 词典，不联网），**已有的值不会被覆盖**——专名（Dunhuang / Mogao / Peking Opera / Shaanxi…）与英式拼写是手工补的；新词缺音标时跑一次 `build_ipa.py` 自动补，仍缺的按提示手工填进同一个 JSON；
- 托管：GitHub Pages（GitHub Actions 发布 `web/` 目录），公开仓库 [TOBEATIAN/english-practice](https://github.com/TOBEATIAN/english-practice)（2026-09-22 由 `shadow-reading` 改名而来）。

## 开源方案取舍

- **TypeWords**（<https://github.com/zyronon/TypeWords>，GPL-3.0）：成熟度高、功能完整，已有跟写、听写、自测、默写和记忆曲线。本项目借鉴其“输入驱动记忆”的交互思路，但不整体 Fork，避免把一个现有静态学习站改造成 Nuxt 大工程。
- **Qwerty Learner**（<https://github.com/RealKai42/qwerty-learner>，GPL-3.0）：词库与打字记忆做得很完整，同样偏重键盘肌肉记忆。本项目保留其“错误重打、卡片原子化”的思想。
- **ECDICT**（<https://github.com/skywind3000/ECDICT>，MIT）：作为内置词典数据源。选它的原因是许可清晰、可离线、中文释义和词形变化完整，适合直接生成静态站点数据。
- 结论：网站外壳和现有跟读学习链继续复用，词典与词书不自己编；只自行实现本项目特有的“个人生词本 + 中文反向提取 + 语境产出”闭环。
